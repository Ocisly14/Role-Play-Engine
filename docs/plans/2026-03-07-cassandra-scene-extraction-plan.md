# 卡森德拉(Cassandra) 场景提取方案

## 输入

- `testmods/casssandra/scene/scene.md` — 场景原始文档
- `testmods/casssandra/scene/PL地图1.jpg` — 玩家地图

## 输出

可被系统直接加载的 JSON 文件集：

1. `scenarios_outline.json` — 所有大场景列表
2. `Cassandra_Scenarios/[场景名].json` — 每个大场景的子场景详情
3. `transport_network.json` — 街道 road scenes + transport edges

## 提取范围

- **提取**：静态场景信息（描述、物品、线索、场景内连接关系）
- **不提取**：事件性内容（NPC死亡、战斗遭遇、条件触发等）

## ID 规则

- 大场景：`SCN_1` ~ `SCN_N`
- 街道场景：`ROAD_1` ~ `ROAD_N`
- 子场景：`SCN_X_SUB_Y`（X=大场景编号，Y=子场景序号，1=entry scene）
