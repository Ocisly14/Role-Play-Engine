# Sanity WorldFeature Design

> CoC 7e faithful sanity/insanity system as a WorldFeature plugin.

**Goal:** Implement automatic insanity triggers, bout of madness effects, and duration management when characters lose SAN — currently SAN loss has zero mechanical consequences.

**Architecture:** Event-driven `applySanityLoss()` utility replaces all direct SAN mutations. The function applies the delta, logs it, checks triggers, and injects conditions. `tick()` manages durations and cleanup.

**Scope:** Single-player only (`dynamicBasicAgent` / `engine` / `state`).

---

## Core Mechanics

### Triggers

1. **Temporary Insanity** — single SAN loss event ≥ 5 points
   - Duration: 1d10 game hours
   - Resolves automatically via tick countdown

2. **Indefinite Insanity** — cumulative SAN loss within 1 game hour ≥ 1/5 of current SAN
   - Onset delay: 1d6 game hours (character seems OK at first, then breaks down)
   - Duration: 1d10 game days
   - Can be cured early via Psychoanalysis skill check

### Bout of Madness Table (d10)

| Roll | Type | ActionRestriction | Persistent? |
|------|------|-------------------|-------------|
| 1 | Amnesia | `impaired` | No |
| 2 | Psychosomatic disability | `impaired` | No |
| 3 | Violence | `attack_only` | No |
| 4 | Paranoia | `impaired` | No |
| 5 | Significant person fixation | `impaired` | No |
| 6 | Faint | `incapacitated` | No |
| 7 | Flee in panic | `flee_only` | No |
| 8 | Physical hysterics | `incapacitated` | No |
| 9 | Phobia | `impaired` | Yes — persists after insanity resolves |
| 10 | Mania | `impaired` | Yes — persists after insanity resolves |

- Phobia/Mania specific subject generated by small LLM model using triggering scene + action context.

### ActionRestriction Types

- `none` — no restriction (normal state)
- `incapacitated` — cannot act (faint, hysterics)
- `flee_only` — must flee, no other actions
- `attack_only` — attacks nearest target, no other actions
- `impaired` — can act but with distorted perception/judgment

## Per-Character State

```typescript
interface SanityCharacterState {
  sanLossLog: Array<{ amount: number; gameTimeMinutes: number }>;
  activeInsanity: {
    insanityType: "temporary" | "indefinite";
    boutType: BoutOfMadnessType;
    description: string;
    actionRestriction: ActionRestriction;
    startMinutes: number;
    durationMinutes: number;
    isActive: boolean;           // indefinite: false during onset delay
    onsetDelayMinutes?: number;  // indefinite only
  } | null;
  persistentConditions: Array<{
    type: "phobia" | "mania";
    subject: string;
    description: string;
  }>;
}
```

## applySanityLoss Flow

```
applySanityLoss(dgsm, characterId, delta, isPlayer, runtime, source?)
  1. Apply SAN delta (existing updateNpcSan or direct mutation)
  2. Record in sanLossLog with current gameTime
  3. Single-event check: |delta| >= 5 → temporary insanity
     - Roll 1d10 hours duration
     - Roll d10 bout of madness table
     - If phobia/mania → call small LLM for specific subject
     - Inject condition with [Insanity] prefix + actionRestriction tag
  4. Hourly cumulative check: sum(last 60 min losses) >= currentSan / 5 → indefinite insanity
     - Roll 1d6 hours onset delay
     - Roll 1d10 days duration
     - Roll d10 bout of madness table
     - If phobia/mania → call small LLM for specific subject
     - Store but don't inject condition yet (wait for onset)
  5. Priority: if both trigger simultaneously, temporary takes effect first
```

---

## tick() Behavior

```
tick():
  for each character with sanity state:
    1. Indefinite insanity onset check:
       - If !isActive && onset delay elapsed → set isActive, inject condition
    2. Duration expiry check:
       - If isActive && duration elapsed → clear activeInsanity, remove condition
       - Persistent phobia/mania conditions remain
    3. Cleanup sanLossLog entries older than 1 game hour
```

## Condition Format

```
[Insanity:temporary] Flee — 恐惧吞噬了理智，疯狂地奔逃 | restriction:flee_only
[Insanity:indefinite] Violence — 理智崩溃，抓起手边任何东西攻击周围的人 | restriction:attack_only
[Insanity:phobia] 触手恐惧症 — 看到任何触手状物体会陷入极度恐慌 | persistent
[Insanity:mania] 收集癖 — 无法抑制地收集一切闪亮的物品 | persistent
```
